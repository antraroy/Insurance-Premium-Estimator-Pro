# 🏥 Health Insurance Premium Estimator Pro

An interactive Machine Learning web application that predicts health insurance premiums based on customer information. It provides model comparisons, prediction insights, what-if analysis, and long-term premium projections.

🚀 **Live Demo:** [Try the App](PASTE_YOUR_STREAMLIT_LINK_HERE)

## ✨ Features

- 💰 Health insurance premium prediction
- 🤖 Machine Learning model comparison
- 📊 Actual vs. predicted visualization
- 🔍 Prediction insights and explainability
- 🧪 What-if scenario analysis
- 📈 10-year premium cost projection
- 🖥️ Interactive web interface built with Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly

## 🎯 Project Objective

The objective of this project is to use Machine Learning to estimate health insurance premiums based on customer characteristics and provide insights into the factors influencing insurance costs.
